Nibbles

Haciendo el escaneo típico con nmap podemos ver el puerto 22 y 80 abiertos. Si vamos a la página web podemos ver como solo hay un hello world pero si vemos el código fuente vemos una ruta /nibbleblog/ por lo tanto vamos para allá y vemos un blog.

Usando gobuster para fuzzear vemos el directorio /admin.php al cual podemos acceder con el usuario admin y la password nibbles. El usuario se leakea en una de las búsquedas de [gobuster]() pero la contraseña hay que adivinarla.

Una vez dentro vemos la versión de nibbleblog, la cual es vulnerable a subida de archivos maliciosos.

Echándole un ojo a un github sobre la vulnerabilidad podemos ver las rutas donde se llevan a cabo dicha vulnerabilidad y la hacemos nosotros de manera manual.

Una vez subimos el archivo tenemos capacidad de ejecutar comandos y nos entablamos una reverse shell.

Escalada de privilegios

En la escalada de privilegios podemos ver como tenemos asignado un poder de sudoer de manera relativa, por lo que nos creamos el directorio y el script en bash donde nosostros queremos y en el script convertimos la bash en suid y ya escalamos privilegios.
