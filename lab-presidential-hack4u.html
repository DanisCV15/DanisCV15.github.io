Antes que nada, lo primero que hacemos es ver los archivos .conf para ver si podemos encontrar algún tipo de contraseña hardcodeada.

Como no encontramos nada decidimos convertirnos a admin ya que tenemos su contraseña:

Una vez después de escalar privilegios lo primero que hacemos es ver si pertenecemos a algún grupo especial con el comando id, no vemos nada.

Después buscamos permisos suid especiales con el comando find / -perm -4000 2>/dev/null y no encontramos nada importante.

También miramos si el usuario admin tiene capacidad de uso de sudo con el comando sudo -l pero vemos que no tiene nada.

El siguiente paso es buscar capabilities:

De hecho vemos varias capabilities interesantes, pero la única que funcionará es cap_dac_read_search+ep que nos permite listar cualquier fichero del sistema.

Con esta capabilities realizamos el siguiente comando tarS -cvf id_rsa.tar /root/.ssh/id_rsa para crear un comprimido de la clave privada de root. Luego lo descomprimimos para ver si lo tenemos y efectivamente ha funcionado.

Gracias a esto vamos a probar si conectándonos por el puerto 2082 como root nos lo permite.

Con el siguiente comando lo llevaremos a cabo: ssh -i id_rsa root@localhost -p 2082
