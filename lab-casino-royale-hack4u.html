Escalada de privilegios

Lo primero que haremos al tener acceso a la máquina, es buscar archivos .conf que se hayan utilizado para montar todo el sistema web.

Normalmente hay información sensible en estos archivos.

Usamos el comando find -name \*conf\* -exec cat {} /; | less -S

Con este comando buscamos en el directorio base de todo el tinglado de las páginas web para buscar por archivos que contengan la palabra conf y luego nos ejecuta un cat a todo para leer lo que hay dentro y buscar algo de información útil.

Al hacer esto podemos ver que está el usuario valenka y su contraseña, la cual principalmente es par la base de datos, pero si la probamos al hacer un cambio de usuario nos lo permite.

Al estar como usuario valenka, nos vamos a su home para ver si hay algo interesante.

Echamos un vistazo a su .bash_history y podemos ver que hay algo de Tareas cron.

Echamos un vistazo con crontab -l para ver si hay alguna tarea cron de valenka ejecutándose y no hay nada.

Miramos también systemctl list-timers para ver si hay algo ejecutándose a intervalos regulares de tiempo de lo que nos podamos aprovechar. En principio nada, todo tiene un tiempo de ejecución super alto.
